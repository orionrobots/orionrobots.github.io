## What you will build

The book takes you from an empty Raspberry Pi to a robot that drives, senses, sees and listens, all programmed in Python. Along the way you will:

- Set up a headless Raspberry Pi and protect your robot code with Git.
- Build the robot - wheels, power and wiring - then drive and turn with Python.
- Drive the robot from your phone, and see its state on interactive dashboards.
- Read distance sensors and use them to avoid obstacles.
- Control servo motors, and read encoders and an IMU (the BNO055) to work out where the robot is and how it is moving.
- Give it eyes with a Pi camera and OpenCV, and follow a line with it.
- Talk to the robot with offline voice recognition using Vosk.
- Automate installs and updates, so it is easy to keep your robot up to date.

## Who it is for

If you are a software engineer who wants to get into hardware, a maker, a parent building with a child, or a teacher looking for a challenging project, this is for you. You need only a little Python - loops, conditionals and functions. There is no soldering, and you do not need a workshop.
